xAI 推出 The X Subscription 整合 Grok、Grok Bot、Cursor 与 X Premium

正文 · AI 翻译
中文原文

Grok、Grok Bot、Cursor 和 X Premium，全部包含在一个套餐中。

今天我们推出 The X Subscription，将 Grok、Grok Bot、Cursor 和 X Premium 整合到一个套餐中。在接下来的几天里，我们将面向全球所有人开放。

这是首次，一个 AI 订阅支持从思考和创作到构建和分享的完整流程。

  • Grok 支持聊天、语音以及图像和视频生成。
  • Grok Bot 为你提供能完成工作的 AI 队友。
  • Cursor 提供领先的本地和云端编码智能体。
  • X 增加认证标记、创作者工具和更少广告，更高档位则完全移除时间线中的广告。

The X Subscription 的付费套餐包含一个充裕的 Grok 模型使用额度池，可在 Grok 和 Cursor 之间共享。每个可比的新档位都比它所替代的套餐提供更高的每美元使用量。

无论你是在 Grok 应用、X 上的 Grok 标签页还是 Cursor 中使用 Grok 模型，你的共享额度池都覆盖这些模型。每个 X Subscription 套餐包含的我们模型编码使用量至少是可比 Cursor 套餐的两倍。使用新套餐后，第三方模型仍可在 Premium 及以上档位的 Cursor 中使用。使用量按 API 标价单独计费，通过充值支付。

The X Subscription 从今天起面向新客户开放。

我们也在为现有的 SuperGrok、Cursor 和 X Premium 订阅用户推出切换选项。当该选项对你可用时，你会在账户账单设置中看到它。你可以保留当前套餐，或切换并按比例获得旧套餐的退款。

套餐与定价

The X Subscription 让你以大致相当于这些产品中某一个的可比独立套餐过去的价格，获得 Grok、Cursor 和 X。

套餐价格包含内容包含使用量
Free$0每日可使用 Grok、Cursor 编码智能体的入门额度，以及标准 X有限
Plus$8/月Grok 和 Cursor 中更多 AI 使用量，外加 X 上的认证标记、创作者工具和更少广告基础
Premium$30/月SuperGrok、Cursor Pro 和 X Premium+ 的权益，此前合计为 $90/月4 倍 Plus 套餐
Super$100/月以上所有功能15 倍 Plus 套餐
Ultra$200/月以上所有功能50 倍 Plus 套餐

有关定价、包含使用量和资格的更多详情，请参阅定价页面。

面向团队和企业的一个订阅

团队用户可享受 The X Subscription 的 Premium、Super 和 Ultra，每席位价格与个人套餐相同。其每席位价格低于旧的 Cursor Teams，但现在包含 3 倍以上的编码使用量，外加 SSO、管理员控制、合并账单、使用量分析和 SOC 2 合规。

企业客户可从一个仪表板管理 Grok 和 Cursor，两个产品共用一个使用量池。我们的销售团队随时准备帮助你开始使用。

保留你当前的套餐或迁移到 The X Subscription

对于现有的 SuperGrok、Cursor 或 X Premium 订阅用户，一切不变。你可以保留当前的套餐、价格和功能，或迁移到 The X Subscription。

切换附带限时优惠，你可以在账户账单设置中查看。

开始使用

在 x.ai/pricing 比较套餐并注册。

如果你已订阅 SuperGrok、Cursor 或 X Premium，请前往账单设置，查看你的账户是否已可切换。
